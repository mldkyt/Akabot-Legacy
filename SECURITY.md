# Security Policy

## Supported Versions

The following versions are supported.
The latest version, currently 1.3 is fully supported and new features are added to it.
Any previous version is unsupported.

| Version | Supported                                      |
|---------|------------------------------------------------|
| 1.0     | ✅ Fully supported and under active development |
| 4.x     | ⚠ Bugs and vulnerability fixes only            |
| 3.x     | ❌ Unsupported                                  |
| 2.x     | ❌ Unsupported                                  |

## Reporting a Vulnerability

### From the bot

1. Go to a server with the bot itself.
2. Run `/feedback bug`
3. Fill out the form
4. The bot will create an issue.

### From GitHub

1. Go to Issues.
2. Create an issue.
3. Fill out the information.
4. Submit your issue.

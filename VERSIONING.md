# Akabot Versioning System

## Versioning Scheme

`<major>.<feature>.<fix>`

### Major

This will probably never be changed. This will always stay at "1", regardless of any bigger updates.

### Feature

This gets bumped when there's any major updates to the visible part of Akabot (e.g. new features, feature edits...). If
there's a huge database update, for example, this won't be changed.

### Fix

This only changes if there's a small bugfix or an update that doesn't change the behavior of the bot visibly.
